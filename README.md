# Rain Forecasting Power BI Dashboard
## Project Overview
This Project present an interactive Power BI dashboard developed to analyze historical rainfall data and identify rainfall trends, seasonal patterns, and yearly variations. 
The dashboard provides a clear and interactive view of rainfall performance using KPIs, Charts, and Slicers.

## Objectives
- Analyze historical rainfall data
- Identify yearly rainfall trends
- Analyze monthly rainfall patterns
- Compare seasonal rainfall
- Analyze monsoon rainfall
- Identify high and low rainfall periods
- Create an interactive and user friendly dashboard 

## Tools & Technology
- Microsoft Power BI
- Power Query
- Dax
- Data visualization
- Data Cleaning & Transformation

## Dashboard Features

### KPI Metrics
- Total Rainfall
- Average Rainfall
- Maximum Rainfall
- Minimum Rainfall
- Rainfall variability

### Visualizations
- Year-wise Rainfall
- Month-wise Rainfall
- Seasonal Rainfall
- Monsoon Rainfall
- Rainfall Trend
- Rainfall Category
- Monthly Rainfall Comparison

### Filters
- Year
- Month
- Season
- Rainfall Category
